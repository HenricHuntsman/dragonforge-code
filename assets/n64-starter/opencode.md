# N64 coding lab — project instructions

This is an isolated lab, not a location for users' original Nintendo 64 ROMs or active reverse-engineering repos.
Before assisting with Nintendo 64 work, call the `skill` tool with `{ "name": "n64-dev" }` and follow the returned instructions.
Use synthetic headers and fixtures by default. Ask before any file edits or shell commands. Treat supplied ROMs as read-only, and never alter a ROM without a separate, explicit user decision.
Do not access, modify, reset, clean, commit, or push the separate TraceForge, M64Tool, RomForge64, and Hyrule Reborn directories.
