# 🎈 Welcome Back, OpenCode — DragonForge Code 🐉

Welcome to the homecoming of the historic OpenCode Go coding agent and the independent DragonForge Code project.

## A special place for v0.0.56

**v0.0.56 is our homecoming milestone.** It represents a treasured historical release in the project's revival story, not a claim that DragonForge's maintainer authored the original software. We preserve its identity, history, and provenance separately from new DragonForge releases.

🎉 **Welcome back, OpenCode!** 🎈

The goal is to preserve what came before, acknowledge the people who built it, and keep developing an independent, local-first coding agent.

## Credit where it belongs

The original OpenCode Go project was created by its original contributors. DragonForge builds on that MIT-licensed work and subsequent revival contributions. See [LICENSE](LICENSE), [the previous revival README](docs/OPENCODE-REVIVAL-README.md), and [the upstream archive index](docs/upstream/README.md). Keep original copyright and licence notices intact.

## What we are preserving

The inherited source includes an interactive Go terminal coding agent and its historical development work. For an accurate description of current functionality, consult the source, run the tests, and distinguish historical implementations from verified DragonForge behaviour.

## Where DragonForge goes next

- Maintain the independent Go coding agent and local-first workflows.
- Test the Ollama-compatible endpoint and local model integration.
- Preserve original releases, tags, branches, and upstream attribution.
- Document existing features and known gaps before promising new ones.
- Evaluate ForgeTerminal, Greenlight, Nintendo 64, and TraceForge connections as **future or separate integrations**, not already-shipped DragonForge features.
